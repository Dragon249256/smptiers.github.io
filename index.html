How the system works

This system creates one shared rank ladder that is independent of kit choice. Every rank is its own player position, and each kit is shown separately as unranked.

  • #1 is the highest rank.
  • #60 is the lowest rank.
  • Kits are available across all ranks without automatic assignment.
  • Use this page as a clean Multicraft tier system reference.

Global ranking

One rank list from best to worst, visible across every kit lineup.

Kit independence

Each kit is displayed as unranked for all ranks until you fill it yourself.
